# AI Agent Web Interaction Traces

This example demonstrates how an AI agent can gain "visual intelligence" by moving beyond static "page snapshots" to dynamic "interaction traces." It simulates a simple interactive web page, showing how an initial snapshot captures only the static state, while subsequent user actions and their resulting state changes are recorded as a chronological trace. This trace provides a richer understanding of user behavior and page dynamics.

## Language

`html`

## How to Run

Save the code as `index.html`.
Open `index.html` in any modern web browser.
Interact with the buttons and input field to see the "Interaction Trace" update.
